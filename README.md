# El Chip Desktop

A python program that randomly pops up with El Chip's ads to promote his restaurant.

## Configuring El Chip Desktop

The program is based on game logic and will show on randomly based on difficulty ranging from 1 to 20.\
The app will remain hidden when the pop up is hidden, to configure it check your system tray.\
You then can right-click the icon to configure it, close it or force a pop-up to show.\
THe config is based on UCN logic, it will be way more frequent on 20 and very rare on 1.
